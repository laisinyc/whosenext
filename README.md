实现一个餐厅服务员排序小程序，要求如下

1. 程序配置
    1. 可以添加删除服务员名字
    2. 可以配置餐桌的代号和最多可坐人数
2. 早上开始前，勾选当天在职服务员
3. 初始化：按照当天勾选服务员的顺序排序
4. 当有客人来时候
    1. 分配当前服务员
    2. 当前服务员服务人数增加对应数量，记录桌号
5. 下一位服务员的排序规则
    1. 服务人数最少的优先
    2. 当服务数量相同时，按照初始化顺序自上而下选择
6. 共享桌处理
    1. 当人数超过5(不含)人时为共享桌
    2. 共享桌不记录人数，只记录桌号
7. 有时候客人会要求更改桌位或者临时增加人数，提供改动对应条目的popup
8. 桌位占位与释放
    1. 选择桌子并分配人数后，该桌在「客人到店」的餐桌列表里显示为红色“占位”（附服务员和人数），不能再被分配给新客人
    2. 再次点击占位桌，弹出 popup，可「释放占位」（客人离开）、「修改分配」或取消
    3. 释放只是让桌子重新可用，服务员已记录的人数、桌数、日志都不变；释放动作会写入日志
    4. 「撤销」或在修改 popup 中「删除」某条分配，该桌也会自动恢复可用
    5. 修改 popup 里换桌时，被其他客人占位的桌子不可选
    6. 服务情况里已释放的条目显示为淡色加删除线
9. 一天分成上午班 / 晚班
    1. 晚班从 16:30 开始（可在 config.js 的 `eveningStart` 修改），之前为上午班
    2. 当天的日志按时间自动分成上午班、晚班两部分显示；导出的 .txt 也分成两段
    3. 结束营业时，汇总分别给出全天、上午班、晚班每位服务员的人数、桌数、桌号（按客人入座时间归班次）
    4. 班次只用于记录和汇总，不会重新排序，服务人数仍按全天累计
10. 撤销 / 重做
    1. 「客人到店」卡片右上角有 撤销 ↶ / 重做 ↷ 图标按钮（桌面端也可用 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z）
    2. 分配、修改、删除、释放占位都可以撤销和重做；鼠标悬停（长按）按钮可看到将要撤销/重做的是哪一步
    3. 撤销/重做会在日志里各留一条记录，日志本身不回退
    4. 最多保留 50 步；做了新的操作后，重做记录清空；结束营业后全部清空
11. 按钮图标：只有 撤销、重做 使用图标，其余按钮保持文字
\n12. 餐桌按平面图排列
    1. 「客人到店」和「修改分配」弹窗里的餐桌按钮，按餐厅俯瞰图的位置排列：S123 在第一行，A1-A6 第一列，B 系列第二列，C 系列第三列，E2、E1 第四列（B23、B45、C23、C45 各占两行）
    2. 排列在 config.js 的 `tableLayout` 里用文字描述（每行一个字符串，空格分隔格子，`.` 为空位，同一桌号占相邻格子即跨行/跨列），改完刷新页面即可生效
    3. 没写进 `tableLayout` 的桌子会排在下面；删掉 `tableLayout` 则恢复为普通顺序排列
