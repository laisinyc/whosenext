实现一个餐厅服务员排序小程序，要求如下

1. 程序配置
    1. 可以添加删除服务员名字
    2. 可以配置餐桌的代号和最多可坐人数
2. 早上开始前，勾选当天在职服务员
3. 初始化：按照当天勾选服务员的顺序排序
4. 当有客人来时候
    1. 分配当前服务员
    2. 当前服务员服务人数增加对应数量，记录桌号
5. 下一位服务员的排序规则
    1. 服务人数最少的优先
    2. 当服务数量相同时，按照初始化顺序自上而下选择
6. 共享桌处理
    1. 当人数超过5(不含)人时为共享桌
    2. 共享桌不记录人数，只记录桌号
7. 有时候客人会要求更改桌位或者临时增加人数，提供改动对应条目的popup
